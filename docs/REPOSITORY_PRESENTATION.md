## Maintenance

The source is `scripts/showcase_panels.py` in the profile repository. Use `make(kind, narrow, animated)` for each repository's four SVGs; its `.github/showcase/README.md` records its kind. The profile uses 28 assets; repository copies add 36 assets. Original reference graphics were not copied.

Animations are explanatory artwork. They do not establish runtime verification, benchmark results or deployment status. Existing contribution boundaries, upstream authorship, project setup instructions and synthetic-commit disclosure must remain intact.
